# Ecar Design System - EDS

Uma biblioteca de componentes reutilizáveis, padrões visuais e diretrizes de interface para os produtos digitais da Ecar Fleet.

## Nossa identidade

Construímos interfaces consistentes, acessíveis e funcionais, seguindo a identidade visual da Ecar Fleet.

## Fundamentos

- **Cores:** amarelo/dourado, preto, branco e tons de cinza.
- **Tipografia:** Manrope para títulos e Inter para textos.
- **Componentes:** elementos reutilizáveis com estados e tamanhos definidos.
- **Acessibilidade:** foco visível, navegação por teclado e estados compreensíveis.

## Componentes disponíveis

Começamos com o componente Button, que possui variantes primária e secundária, três tamanhos e estado desabilitado.

Explore a categoria **Components → Button** no menu lateral para visualizar os exemplos.

## Estrutura do projeto

- **Foundations:** cores, tipografia, espaçamento e bordas.
- **Components:** botões, campos, cartões e outros elementos.
- **Patterns:** combinações de componentes para situações recorrentes.

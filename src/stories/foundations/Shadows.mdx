# Shadows

Os tokens de sombra definem a profundidade visual dos elementos da interface. Eles ajudam a estabelecer hierarquia entre superfícies e destacar componentes que aparecem acima do conteúdo principal.

O Ecar Design System utiliza níveis progressivos de elevação, desde elementos discretos até camadas de maior destaque.

## Princípios

- Utilizar sombras para comunicar profundidade e hierarquia.
- Evitar sombras excessivamente fortes.
- Manter consistência entre componentes com o mesmo nível de elevação.
- Não utilizar sombras como substitutas de bordas quando a separação estrutural for necessária.
- Priorizar os tokens definidos em `src/styles/tokens.css`.

## 1. Shadow scale

| Token           | Valor                          | Aplicação              |
| --------------- | ------------------------------ | ---------------------- |
| `--shadow-none` | `none`                         | Sem sombra             |
| `--shadow-xs`   | `0 1px 2px rgb(0 0 0 / 6%)`    | Elevação mínima        |
| `--shadow-sm`   | `0 1px 3px rgb(0 0 0 / 10%)`   | Elementos discretos    |
| `--shadow-md`   | `0 4px 12px rgb(0 0 0 / 12%)`  | Elevação intermediária |
| `--shadow-lg`   | `0 8px 24px rgb(0 0 0 / 14%)`  | Elementos destacados   |
| `--shadow-xl`   | `0 16px 40px rgb(0 0 0 / 16%)` | Camadas superiores     |

## 2. Recommended applications

| Componente                  | Token recomendado |
| --------------------------- | ----------------- |
| Elementos sem elevação      | `--shadow-none`   |
| Cards discretos             | `--shadow-xs`     |
| Cards destacados            | `--shadow-sm`     |
| Dropdowns e menus           | `--shadow-md`     |
| Popovers                    | `--shadow-lg`     |
| Modais e camadas superiores | `--shadow-xl`     |

Essas aplicações são referências iniciais. A escolha final deve considerar o contexto visual e a hierarquia do componente.

## 4. Como utilizar os tokens

### Exemplo: card

```css
.card {
  background: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: var(--radius-lg);
  box-shadow: var(--shadow-sm);
}
```

### Exemplo: dropdown

```css
.dropdown-menu {
  background: var(--color-surface);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-md);
}
```

### Exemplo: modal

```css
.modal {
  background: var(--color-surface);
  border-radius: var(--radius-xl);
  box-shadow: var(--shadow-xl);
}
```

---

## 5. Regras de utilização

1. Não utilizar sombras fortes em todos os componentes.
2. Reservar níveis elevados para elementos que realmente precisam se destacar.
3. Manter consistência entre componentes com funções semelhantes.
4. Evitar combinar múltiplas sombras sem necessidade.
5. Não depender exclusivamente de sombras para comunicar hierarquia.
6. Considerar a aparência das sombras em fundos claros e escuros.

# Colors

A paleta de cores estabelece a identidade visual do Ecar Fleet e define como informações, superfícies e estados são apresentados na interface.

As cores são organizadas por finalidade para facilitar a aplicação consistente em todos os componentes.

## Princípios

- Utilizar as cores da marca de forma consistente.
- Priorizar contraste e legibilidade.
- Utilizar cores semânticas para comunicar estados.
- Evitar valores de cores fixos diretamente nos componentes.
- Utilizar os tokens definidos em `src/styles/tokens.css`.

---

## 1. Brand colors

Cores principais da identidade visual do Ecar Fleet.

| Token                   | Valor     | Aplicação              |
| ----------------------- | --------- | ---------------------- |
| `--color-brand-primary` | `#FFB900` | Cor principal da marca |
| `--color-brand-hover`   | `#E5A600` | Estado hover           |
| `--color-brand-active`  | `#CC9400` | Estado active          |

### Visualização

<div
  style={{
    display: "grid",
    gridTemplateColumns: "repeat(auto-fit, minmax(180px, 1fr))",
    gap: "16px",
  }}
>
  {[
    { name: "Primary", token: "color-brand-primary" },
    { name: "Hover", token: "color-brand-hover" },
    { name: "Active", token: "color-brand-active" },
  ].map((item) => (
    <div key={item.token}>
      <div
        style={{
          height: "90px",
          background: `var(--${item.token})`,
          borderRadius: "var(--radius-md)",
          border: "1px solid var(--color-border)",
        }}
      />
      <strong style={{ display: "block", marginTop: "8px", fontSize: "13px" }}>
        {item.name}
      </strong>
      <code style={{ fontSize: "12px" }}>var(--{item.token})</code>
    </div>
  ))}
</div>

### Recomendações

- **Primary:** ações principais, elementos de identidade e destaques.
- **Hover:** interação ao posicionar o cursor sobre elementos acionáveis.
- **Active:** estado de pressionamento ou ativação.

## 5. Semantic colors

Cores utilizadas para comunicar estados e resultados de operações.

| Token             | Valor     | Significado               |
| ----------------- | --------- | ------------------------- |
| `--color-success` | `#15803D` | Sucesso e conclusão       |
| `--color-warning` | `#B45309` | Atenção e alerta          |
| `--color-danger`  | `#DC2626` | Erros e ações críticas    |
| `--color-info`    | `#2563EB` | Informações e orientações |

### Visualização

<div
  style={{

  }}
>
  {[
    { name: "Success", token: "color-success" },
    { name: "Warning", token: "color-warning" },
    { name: "Danger", token: "color-danger" },
    { name: "Info", token: "color-info" },
  ].map((item) => (
    <div key={item.token}>
      <div
        style={{
          height: "64px",
          background: `var(--${item.token})`,
          borderRadius: "var(--radius-md)",
        }}

      <strong style={{ display: "block", marginTop: "8px", fontSize: "13px" }}>
        {item.name}
      </strong>
      <code style={{ fontSize: "12px" }}>var(--{item.token})</code>
    </div>
  ))}
</div>

### Aplicações

- **Success:** operação concluída, veículo disponível ou processo aprovado.
- **Warning:** manutenção próxima, pendência ou situação que exige atenção.
- **Danger:** falha, erro, bloqueio ou operação crítica.
- **Info:** orientação, atualização ou informação complementar.

Cores semânticas devem ser acompanhadas de texto, ícone ou outro indicador. Não dependa exclusivamente da cor para comunicar um estado.

## 6. Como utilizar os tokens

### Exemplo: botão principal

```css
.button-primary {
  background: var(--color-brand-primary);
  color: var(--color-text-primary);
}

.button-primary:hover {
  background: var(--color-brand-hover);
}

.button-primary:active {
  background: var(--color-brand-active);
}
```

### Exemplo: card

```css
.card {
  background: var(--color-surface);
  color: var(--color-text-primary);
  border: 1px solid var(--color-border);
}
```

### Exemplo: status

```css
.status-success {
  color: var(--color-success);
}

.status-warning {
  color: var(--color-warning);
}

.status-danger {
  color: var(--color-danger);
}

.status-info {
  color: var(--color-info);
}
```

---

## 7. Regras de utilização

1. Utilizar os tokens de marca para preservar a identidade visual.
2. Manter contraste suficiente entre texto e fundo.
3. Utilizar cores semânticas de acordo com seu significado.
4. Não utilizar cores semânticas como decoração sem justificativa.
5. Evitar valores hexadecimais diretamente nos estilos dos componentes.
6. Não depender exclusivamente de cores para transmitir informações.
7. Testar estados de interação e acessibilidade.

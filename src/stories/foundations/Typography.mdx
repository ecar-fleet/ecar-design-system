# Typography

A tipografia define como as informações são apresentadas na interface. Ela estabelece hierarquia visual, facilita a leitura e mantém a identidade visual do Ecar Fleet.

O sistema utiliza a família tipográfica **Inter**, com diferentes tamanhos, pesos e alturas de linha.

## Princípios

- Priorizar legibilidade em todas as resoluções.
- Utilizar pesos tipográficos para estabelecer hierarquia.
- Manter consistência entre títulos, textos, descrições e informações auxiliares.
- Evitar tamanhos e pesos arbitrários.
- Utilizar os tokens tipográficos definidos em `src/styles/tokens.css`.

## 2. Font sizes

Os tamanhos tipográficos definem os níveis de hierarquia da interface.

| Token             | Valor | Aplicação              |
| ----------------- | ----: | ---------------------- |
| `--font-size-xs`  |  12px | Informações auxiliares |
| `--font-size-sm`  |  14px | Textos secundários     |
| `--font-size-md`  |  16px | Texto padrão           |
| `--font-size-lg`  |  18px | Textos de destaque     |
| `--font-size-xl`  |  24px | Títulos de seção       |
| `--font-size-2xl` |  32px | Títulos principais     |

### Visualização

<div style={{ display: "flex", flexDirection: "column", gap: "20px" }}>
  {[
    { name: "Extra Small", token: "font-size-xs" },
    { name: "Small", token: "font-size-sm" },
    { name: "Medium", token: "font-size-md" },
    { name: "Large", token: "font-size-lg" },
    { name: "Extra Large", token: "font-size-xl" },
    { name: "2X Large", token: "font-size-2xl" },
  ].map((item) => (
    <div
      key={item.token}
      style={{ display: "flex", flexDirection: "column", gap: "4px" }}
    >
      <code style={{ fontSize: "12px" }}>--{item.token}</code>
      <span style={{ fontSize: `var(--${item.token})`, lineHeight: 1.3 }}>
        Ecar Fleet — Typography
      </span>
    </div>
  ))}
</div>

### Recomendações

- **12px:** legendas, metadados e informações auxiliares.
- **14px:** descrições, textos secundários e labels.
- **16px:** texto padrão de leitura.
- **18px:** textos de destaque e introduções.
- **24px:** títulos de seções.
- **32px:** títulos principais de páginas.

## 3. Font weights

Os pesos tipográficos determinam a intensidade visual dos textos.

| Token                     | Valor | Aplicação                   |
| ------------------------- | ----: | --------------------------- |
| `--font-weight-regular`   |   400 | Textos comuns               |
| `--font-weight-medium`    |   500 | Labels e textos de apoio    |
| `--font-weight-semibold`  |   600 | Títulos de componentes      |
| `--font-weight-bold`      |   700 | Títulos e ações importantes |
| `--font-weight-extrabold` |   800 | Destaques específicos       |

## 4. Line heights

A altura de linha controla o espaçamento vertical entre linhas de texto.

| Token                   | Valor | Aplicação     |
| ----------------------- | ----: | ------------- |
| `--line-height-tight`   |  1.25 | Títulos       |
| `--line-height-normal`  |   1.5 | Textos padrão |
| `--line-height-relaxed` |  1.75 | Textos longos |

## 5. Type hierarchy

A combinação dos tokens estabelece uma hierarquia tipográfica consistente.

| Nível           | Tamanho | Peso     | Line height |

| Page title      | 32px    | Bold     | Tight       |
| Section title   | 24px    | Semibold | Tight       |
| Component title | 18px    | Semibold | Normal      |
| Body            | 16px    | Regular  | Normal      |
| Secondary text  | 14px    | Regular  | Normal      |
| Caption         | 12px    | Regular  | Normal      |

## 6. Como utilizar os tokens

### Exemplo: título

```css
.page-title {
  font-family: var(--font-family-heading);
  font-size: var(--font-size-2xl);
  font-weight: var(--font-weight-bold);
  line-height: var(--line-height-tight);
}
```

### Exemplo: texto

```css
.body-text {
  font-family: var(--font-family-body);
  font-size: var(--font-size-md);
  font-weight: var(--font-weight-regular);
  line-height: var(--line-height-normal);
}
```

### Exemplo: texto auxiliar

```css
.caption {
  font-size: var(--font-size-xs);
  font-weight: var(--font-weight-regular);
  line-height: var(--line-height-normal);
  color: var(--color-text-tertiary);
}
```

---

## 7. Regras de utilização

1. Utilizar Inter como família tipográfica padrão.
2. Priorizar os tamanhos definidos nos tokens.
3. Evitar utilizar muitos pesos diferentes no mesmo contexto.
4. Manter contraste adequado entre texto e superfície.
5. Não utilizar textos pequenos para informações essenciais.
6. Utilizar alturas de linha adequadas ao comprimento do conteúdo.
7. Não utilizar apenas o tamanho da fonte para comunicar estados ou importância.
